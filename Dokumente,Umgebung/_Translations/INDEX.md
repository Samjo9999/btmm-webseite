## How to Use This Repository

### For Viewing Documents

1. **Choose your language folder** (e.g., `/EN/` for English)
2. **Select the document** you want (e.g., `BtB_Einfuehrung_v2_2_0_EN.pdf`)
3. **Open in PDF reader** (any standard PDF viewer works)

### For First-Time Users

**Recommended Reading Order:**
1. Start with **BtB_Einfuehrung** (Introduction) in your language
2. Then **BtB_Gemeinschaftskultur** (Community Culture)
3. Then **BTB_Konzept** (Organizational Concept)
4. Then specialized documents as needed

## Document Versions

All documents follow semantic versioning: **vMAJOR.MINOR.PATCH**

Example: `BtB_Einfuehrung_v2_2_0.pdf`
- **v2** = Major version (significant structural changes)
- **.2** = Minor version (content additions/updates)
- **.0** = Patch version (typo fixes, formatting)

When updated, version number increments in filename.

## Technical Information

### System Requirements

- **PDF Reader:** Any modern PDF viewer (Adobe Reader, Preview, etc.)
- **File Size:** 50 KB - 900 KB per document (depends on length)
- **Encoding:** UTF-8 for all text documents
- **RTL Support:** Required for Arabic, Bengali, Hindi text

### Character Support

✓ All languages fully supported in modern PDF readers
✓ Special characters properly encoded
✓ Proper directionality for RTL languages (Arabic)
